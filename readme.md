# Practical Objectives
This exercise is an opportunity to get some practical experience in creating a basic web frontend. Work through the demos to understand the concepts then apply those concepts to the practical exercise. A diagram in the word document shows you the section of the architecture you are working on.

&nbsp;
# PriceList1
This demo shows you how to create a basic HTML file with a **fixed / static** table defined. It also demonstrates:
1. How to add JavaScript event listeners to respond to checkbox and radio button being clicked
2. How to change a style using JavaScript
3. How to change text on the page using JavaScript
4. How to use <div> in html to create a block
5. How to apply styling using a .css file

&nbsp;
# PriceList2
This builds on PriceList1 to show you how to create a dynamic table, built using JavaScript based on an array of data

This is a more realistic approach as the table automatically adjusts for the addition and removal of data in the array

This is a pre-cursor to the html calling an API in later labs where the data is returned from the application server and rendered in the web page using JavaScript so future lab exercises will build on this

&nbsp;
# Running the demos
Open the appropriate html file and press F5 to run the debugger. Choose chrome or whatever browser you want to use from the list. 

The page should be displayed in a browser but this approach provides the opportunity to set breakpoints in the JavaScript for you to debug your code
